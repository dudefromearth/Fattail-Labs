# Amendment AZ-VP-9-A21 — Defaults in Every Dialog

**Date:** 2026-09-18
**Authority:** Coach directive: all settings have a "save as
default" and "reset to default" dropdown.
**Extends:** A9/A10/A20 (the universal dialog) and A11 (presets).
Nothing struck.

## The law

1. **Every settings dialog carries a defaults dropdown** (uniform
   footer, part of the one A10 component), with three actions:
   - **Save as default** — stores the dialog's current values as
     the USER's default for that object.
   - **Reset to default** — restores the user's saved default;
     if none exists, the house default.
   - **Reset to house default** — always available; restores the
     Coach-tuned house values and clears nothing else.
2. **Scope is per object per user** (the dialog's object: a layer,
   an axis, the backdrop, a chip), persisted with the rest of the
   user's surface state; house defaults remain versioned theme/
   config values only Coach changes.
3. **Interplay with modes (A11):** presets snapshot the whole
   surface; object defaults govern what a fresh dialog and "Reset
   to default" restore. A11's reset-to-house-preset remains the
   one-action surface-wide escape hatch.
4. Future dialogs inherit the dropdown by construction (A10.4).

## Standing

Citable law until folded into the SA spec's next authored version.
Surface work binds to A21 from this date.
