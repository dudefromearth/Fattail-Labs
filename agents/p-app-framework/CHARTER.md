# P-App-Framework — Charter

**Project id:** `p-app-framework`  
**Purpose:** Implement the Application Framework as the runtime architecture of Labs —
bounded templates, Display–Edit Mode, component contract, Family A convergence, then
Family B member tools under Member Data & Privacy.

## Success (project-level)

1. **Family A** templates (Course, Hub, Catalog, Resources, Calendar) obey stay-put and
   component contract; AF1–AF7 green with evidence.  
2. **No template builder**; growth by governed construction only.  
3. **Family B** tools ship only after privacy + data-model specs land; isolation and
   consent proven (AF8, AF10–AF11).  
4. Journey **reuses** progress — no second store.  
5. Process-first Trade Log / Journal — no profit-claim product framing.  
6. Decision log complete for F-D\* / T-D\* / Privacy D-\*.

## Explicit non-goals

- MSC code imports  
- Waived Delta gates
