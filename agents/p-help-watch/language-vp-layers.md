# Help Watch — Volume Profile language (AZ-VP-9-A8)

**Standing copy for Sierra.** Not a Help write. Straight-to-main stays blank. Volume Profile Help is **not yet swept**.

**Member mental model:** **one chart, layers you switch on.**

| Arrives as | Names |
|------------|--------|
| **Layer** (toggle on the same canvas) | Volume Profile (identity, default ON) · price chart (default ON) · Structural Analysis (default OFF) · **Footprint** when its gate opens · **GEX overlay** when its gate opens |
| **View** (distinct experience, not a layer) | **Replay** |

Documentation language follows that shape. Do not call Footprint or GEX a "view." Do not call Replay a "layer." SA-L11 navigation still names every phase honestly, IN-DEVELOPMENT included.
