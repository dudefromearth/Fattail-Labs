## Echo — three asks

### 1. Can Session/Print §6 be implemented with the W1 labels without new color grammar?

**Yes.**

§6 is four session/print rows. W1-1 already names each, plus the two Law C rows §6 correctly omits (session class ≠ τ ≠ midnight-ET EXPIRED — India **H4**).

| §6 state | W1 plane badge | W1 package / curve | New color? |
|----------|----------------|--------------------|------------|
| `open` + `live` | **Live** | Numeric **live** mark | No |
| `extended` + `last_print` | **Pre/post** | Numeric **last print** + held disclaimer | No |
| `closed` + `last_print` | **Off market** | Numeric **last print**, labeled held | No |
| `none` | **No print** | Law B **UPDATING** / **CHECK LEGS** | No |

**Last print** is not a seventh badge. It is the package-quality phrase under the number when OPF holds a generation (`extended` or `closed`). §6’s “Named incomplete” is the doctrine *class*; the member word is **No print**. That is assignment, not a second list.

**Color grammar — lock for Charlie (W5), not a new recipe here:**

- Words carry the distinction. Color is not a second vocabulary (HI Spec §2: do not rely on color alone).
- Use the **existing kit**: `color.fill` chips, `color.label` / `color.label.secondary`, existing Law B ALL-CAPS package replacements. No raw hex. No six-mood pastel scale (one hue per W1 row).
- Closed / Pre/post / Held residual / Expired / No print are **expected options states**, not `color.destructive`, not `color.warning` banners, not “connection lost.”
- Live may keep today’s quiet live treatment. It must not become profit-green theater.
- Do **not** mint tokens, components, or a badge primitive in this program’s HOW. As-built Analyzer posture coloring (emerald / sky / amber + `uppercase`) is **as-built chrome**, not this review’s design. W5 maps **W1 sentence case** onto the existing chip. Do not add hues for Held residual / Expired / No print.

Two axes, one kit: market/clock on the plane; print quality on the number. Do not encode those axes as six colors.

## Tango — three asks

Walked as the bleeding trader: short on trust, short on time, already taught by this industry that a red banner means the platform is down or that they should do something *now*.

### 1. Closed / last print does not panic?

**It does not — if Charlie ships the W1 words and not the as-built outage loop.**

§6 member read: *Last known print — the market is closed.* W1 forbids: unavailable · OPF unavailable · error · offline · broken · “no data” · “market down” · a blank cell.

A number under **Off market** is truth. Last print is not an outage (OT-EF B1 · OPF36 · Coach success criterion). The member who sees a debit and **Off market** is being told the tape stopped, not that Labs died.

**Must not ship as panic:**

- Red / destructive treatment on Off market or No print.
- Retry-loop chrome, “reconnect”, or Edit flashing **OPF unavailable** when `print_quality=last_print` (that flash *is* the bug).
- Empty package cell that looks like a crash.

**No print** (`print_quality=none`) is the calm incomplete: *no generation yet — the app is not broken.* Package stays **UPDATING** / **CHECK LEGS**. Not **Error**.

As-built amber “Off market” banner is a W5 consume question, not a spec defect. Tango opinion (not a block): prefer the plane badge + the number over a standing warning strip. Closed is expected. Do not dress it as an incident.

### 2. Extended is not sold as live?

**Correct. W1 and §6 already refuse the sale.**

§6 member read: *Pre/post print — not RTH NBBO.* W1 must-not: Live · open · NBBO · “after-hours live” · “you can lift this” · unavailable · closed · outage.

**Pre/post** names the hours. It does not name a live book. The number is **last print**. The curve is that held print, not an RTH NBBO book.

India **H3** (Coach Accept): `print_quality=live` is forbidden after that contract’s OPF29 instant even if Massive is still printing extended. Tango does not relitigate the law. Tango affirms the member sentence: a settled 0DTE in extended hours is **Held residual** (Law C), never Live, never “still trading.”

Coach already chose the word **Pre/post**. Tango does not replace it (doctrine §11). The companion phrase *not the RTH book* is what keeps a tired member from reading it as a quote they can lift.

### 3. Capacity-over-dependency: told what is true, not what to trade?

**Yes. The word list teaches a distinction. It does not give an order.**

| State | What is true | What it must not become |
|-------|----------------|-------------------------|
| Live | This is the market now | “Lift this” · “enter now” |
| Pre/post | A pre/post print exists; it is not the RTH book | After-hours opportunity · “you can still get filled” |
| Off market | Last known print; the market is closed | Outage · “wait here and we’ll tell you when to trade” |
| Held residual | Settled; still on the card until midnight ET; not live | “Still trading” · “through the close” |
| Expired | This expiration day has ended (after midnight ET). Ghost is the defined debit | “You made / you lost” · **$0** as “worthless” · profit theater |
| No print | No generation yet | Retry · guessed mid · broken app |

Capacity: the member learns live vs last print vs residual vs expired as **named facts**. That is the stop-the-bleeding honesty class (A6: a last print must not render as live).

Dependency would be: hiding the quality so the app “just works,” pulsing Live to pull an action, or pairing a last print with lift-now urgency. W1 already forbids profit theater and lift language. §6: copy is honest; no “unavailable” when OPF has a last print.

Tango does not tell the member what to trade. Hotel (W3-3, parallel) owns false-lift as a trading-honesty block. Tango’s lock is psychological: no panic, no theater, no instruction.
