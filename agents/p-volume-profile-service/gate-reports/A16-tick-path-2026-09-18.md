# A16 tick path — what display consumers can read today

**Law:** A16.1 — scale increments from the **instrument's own tick metadata**, never a hardcoded 0.25 in surface code.

## Source-space (histogram grid)

| Path | What |
|------|------|
| VP envelope `vp_row` | Source-space bin grid. Contract v1.0/v1.1 identity block. ES 0.25 · MES 0.25 · SPY 0.10 on today's payloads. |
| Engine `VP_ROW` dict | Hardcoded in `vp_engine/coverage.py` — **data-end** VP-L3 debt (should be symbol-metadata). Not a surface table. |
| `row=` override | Display rebin of source bins (A14/DL-743). Still source-space. |

A display consumer **may** use `vp_row` as the source instrument's tick. That is already on the payload.

## Target-space (the scale the member sees)

Mapping: `target = source × ratio + offset_published` (Q7(a)). Envelope carries `mapping.ratio` and `mapping.offset_published`. It does **not** carry the **target instrument's tick**.

| Instrument | Native tick (vendor / metadata) | On the VP payload? |
|------------|--------------------------------:|--------------------|
| ES | 0.25 | yes, as `vp_row` (source) |
| MES | 0.25 | yes, as `vp_row` (source) |
| SPY | 0.01 | **no** when viewing XSP via MES (`vp_row` is 0.25) |
| SPX | 0.01 cash | **no** when viewing SPX via ES (`vp_row` is 0.25) |
| XSP | 0.01 | **no** |

`market_symbol_universe` has **no** `tick_size` column. Member universe list does not expose tick. Vendor `/futures/v1/contracts` is ingested for roll set only — tick is not published to display consumers.

**Forbidden:** `vp_row × ratio` as a client stand-in for SPX/XSP tick (that yields 0.25, not 0.01). A16: switching ES→SPX re-derives the scale from **that instrument's** metadata.

## Contract candidate (not implemented this packet)

Do **not** add a client-side table. Candidate for a later contract version (not improvised on v1.1):

```
tick_size          — source instrument native tick (may equal vp_row)
target_tick_size   — displayed instrument native tick (SPX/XSP/ES/…)
```

on the identity block, **or** a computing-class metadata route `GET /v1/instruments/{symbol}` sourced from symbol-metadata / vendor Contracts. Until that field exists, the surface can land source-space scales on `vp_row` and must **not** invent target ticks.
