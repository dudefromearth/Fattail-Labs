## 1. Practice suite

**Entry:** [Apps](/app) → **Practice** (opens Reports) · suite nav on every Practice page: **Trade Log · Reports · Journal · Retrospective · Playbook**.

**Shared chrome (all Practice apps):**

| Feature | What members get |
|---------|------------------|
| **Practice Context — account** | Which book you’re looking at (multi-account). Trades and reports respect account; Journal conversation stays *you*, not per-account. |
| **Practice Context — date** | Shared year/month/week/day lens. Journal = which day; Trade Log = list filter; Reports = analysis window. |
| **Suite nav** | One hop between Practice apps without losing context. |

### 1.1 Trade Log — `/app/trade-log` · **Live**

Your options-first blotter. Process first: structure and fills, not a profit scoreboard.

| Feature | Description |
|---------|-------------|
| Trade table | Permanent log of strategy fills (multi-leg, ToS-style grouping) |
| Right sheet | Create / edit / detail without leaving the table |
| Accounts | Multiple broker or sim books (active account from Practice Context) |
| Import | Bring fills in via adapters (e.g. spreadsheet / platform flows as shipped) |
| Export | Portable book export for your records |
| Deep link | Open a specific trade from Reports or Journal |
| Process framing | Outcomes as process signals — no “hero P&L” framing |

### 1.2 Journal — `/app/journal` · **Live**

Calendar-first process notes: preparation, selection, and review in a conversation per day.

| Feature | Description |
|---------|-------------|
| Calendar | Navigate by day / week / month / year (shared Practice date) |
| Day session | One structured conversation for that date |
| Session agent | Guided process interview (prompts, not stock tips) |
| Tags | Personal + shared vocabulary for later retros and integrity |
| Trade links | See trades from the active account on that day |
| Retrospective type | Start material that feeds the Retrospective ceremony |
| Attachments / notes | Supporting material on the day as shipped |

### 1.3 Retrospective — `/app/retrospective` · **Live**

The formal review ceremony — what held, what broke, what you commit next. Not a P&L autopsy as the headline.

| Feature | Description |
|---------|-------------|
| Library | List of past retrospectives |
| Scope / gather | Since last retro (or maiden journey); preview what will be included |
| Ceremony steps | Structured dual report (process-first, results secondary) |
| Integrity link | Ties into process integrity / cadence expectations |
| Cadence nudges | Gentle reminders when review is due (Journey / practice) |
| Open vs completed | Open retros still work the ceremony; completed are fixed records |

### 1.4 Reports — `/app/reports` · **Live** (Practice home)

Read the path of the book: equity-style path from starting capital, drawdown, and process-oriented tables from Trade Log.

| Feature | Description |
|---------|-------------|
| Equity / balance path | How the selected account’s path evolved (process framing) |
| Drawdown | Capital path risk view |
| Stats / distribution | Performance table without turning Labs into a brag wall |
| Account scope | Same Practice Context account as Trade Log |
| Links into Trade Log | Drill to fills that matter |

### 1.5 Playbook — `/app/playbook` · **Coming soon**

| Intent | Description |
|--------|-------------|
| Personal rule book | Defined-risk setups and rules you actually trade |
| Capacity over dependency | Rules live with you — not only in a coach’s head or a forgotten sheet |
| Until it ships | Use Journal + Trade Log; link to those from the placeholder |

## 2. Journey — `/app/journey` · **Live**

Journey is the **path and standing** surface: how you’re doing on the work that improves long-term success, and (optionally) how you show up as a process peer.

### 2.1 What’s on the page

| Block | Description |
|-------|-------------|
| **Personal process** | Process Integrity meter — habits and consistency (routine, learning, live, adherence, practice persistence, and **Mental Toughness when Toughness is active**). Grades respect tenure; new members are not shamed as “Poor” for starting. |
| **Community presence** | Opt-in board: process pillars only (never profit ranking) |
| **Learning stats** | Enrolled / in progress / completed / lessons completed / watch time |
| **Pathway & next live** | What’s next in the curriculum and calendar |
| **Enrollments** | Courses with resume into the next lesson |
| **Quiz results & activity** | Knowledge checks and recent learning activity |
| **Links** | Profile visibility · Practice suite · Toughness |

### 2.2 How Journey is integral across the Lab

| Surface | What feeds Journey |
|---------|-------------------|
| **Courses** | Enrollments, lesson progress, watch position, completion, quizzes |
| **Live** | Check-in / attendance streak and live-related process signals |
| **Trade Log** | Practice persistence / adherence inputs (process, not P&L rank) |
| **Journal** | Cadence and process documentation |
| **Retrospective** | Review habit and integrity narrative |
| **Toughness** | Mental Toughness dimension **only when** you have an active Hard enrollment |
| **Home (`/home`)** | Continue learning + compact process standing |
| **Profile (`/me`)** | Display name, photo, board opt-in, which pillars you share |

**Member promise:** keep track of practice and progress in one honest place — capacity over dependency, process over pace.

## 3. Toughness — `/app/toughness` · **Live** (optional)

Voluntary capacity training under load (FatTail Hard / True 75). **Never a membership requirement.**

| Feature | Description |
|---------|-------------|
| How it works | Full contract: all required tasks every day; miss → day one; ladder psychology; life events honesty |
| Physiology cite | aMCC / willpower under load; Mental Toughness scores compliance, not a brain scan |
| **True 75 Hard** | Frisella program as-is with full credit; honor-system tracking in Labs |
| **FatTail Hard** | 20 / 40 / 75-day programs; progressive ladder |
| Today’s log | Daily checklist for the active challenge |
| Pause / exit | Leave anytime; MT returns to empty |
| **Journey link** | When enrolled and active, Mental Toughness **enters** Process Integrity; when not enrolled, MT stays empty (does not score zero) |
