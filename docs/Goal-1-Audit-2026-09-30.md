### (symbol, DTE, wings)

DTE is the requested expiration minus the ET calendar date on the access line. Each 502 query line was matched in order to a 502 access line (248,305 of 248,306; one access line had no query line yet). Access is flushed before uvicorn writes the query line, and both sequences are in completion order.

A second pass, a couple of minutes later, counted the query lines alone, with no pairing. Of 249,144 ladder 502 queries, 249,122 name an expiration before Tuesday 2026-09-29. Those are negative DTE on every request in this window, whichever access line they pair with. Twenty-two name a later expiration: 21 are 2026-10-01 and one is 2026-10-08.
