## 4. Estimator law (P0 errata — v2.3.2 still lacks the ratio)

v2.3.2 §9.4.1 writes `move_unit = MOVE_SIGMA × sigma_1min × √(HORIZON_MIN) × spot`. That treats minutes as a naked number and does not say how the **1-minute** bar enters the scale. Two clocks already exist. Naming `MOVE_HORIZON_MIN` does not specify the ratio.

**Required formula (package as v2.3.3 errata; do not implement from the naked `√HORIZON`):**

```
move_unit = MOVE_SIGMA
          × stdev(1-minute underlier log returns over MOVE_WINDOW_MIN)
          × spot
          × sqrt( MOVE_HORIZON_MIN / 1 min )
          [points]
```

`WINDOW` = sample window (default 20). `HORIZON` = adverse-move horizon (default 3, **starting constant**, slice named). If `HORIZON` only replaces `WINDOW`, E37’s 1.3–5.6 min band is incoherent.

Dimensional AT (new, P1): change `HORIZON`, hold `WINDOW`, `move_unit` scales as `√HORIZON`. AT-ALGO-52 (keys are separate) is necessary and not this AT.

2. **Session-net GEX ≠ local §0.2.8.** `gamma_factor` is a percentile of session-net GEX. Coach asked about gamma *around the position*, a heavy strike at the centre, air in the drift direction. A session can be net-positive while the body sits in a hole. Spec already names this (OD-ALGO-4). Do not present the scalar as the local read. Six-vendor comparison owns the upgrade — **not this DAG**.

3. **Two-line teaching inversion.** Legacy is muted and **ratchets**. Proposed is full weight and **breathes**. If the muted ratchet is read as the stop, members flatten on the beginner line and ignore the live one — or the reverse.
