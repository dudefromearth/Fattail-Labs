# Options Lab Heatmap — This tab session

Member-facing guide to Heatmap **inspector choices that stay for this
browser tab**. Teaching only — it does not tell you what to trade and never
promises a profit.

## This tab session
Open Options Lab → Heatmap (`/app/options-lab/heatmap`). The inspector on
the left is your desk: symbol, listed expiration, template, value, Calls or
Puts, and (on Width Fit) your weights and view.

Those choices stay for **this browser tab**. Leave for Analyzer, Surface,
courses, or the Hub, then come back on the **same tab** — the desk is as
you left it. This is the Heatmap’s tab session (sometimes called sticky
selections). A **new tab** starts from defaults.

The live chain is still the held generation. Staying on this tab does not
invent a strike, a mid, or a greek.

## What stays
When you return to Heatmap in this tab, these inspector choices come back:

- **Symbol**, **listed expiration**, **Calls** or **Puts**
- **Template** (Advanced flies, Width Fit, Verticals, and the others)
- **Value** on Advanced flies, and the − / + color slider
- **Width Fit** weights, Expand, Heatmap or Ranking, Live or Average,
  average window (10 / 20 / 50 / 100), and cache size (4 / 8 / 16 / 32 MB)

The strike window is still the held chain.

## What does not stay
These are glance, not desk, and they do **not** come back:

- Hover tips, a pinned inspect panel, or which tile you last clicked
- A copied thinkorswim script
- The color-scale “calm” from a quiet tape (the − / + slider itself does
  come back; the scale it last settled on does not)

**Average** is a view of snapshots this tab has already held in memory. Your
Live / Average choice and window size stay. The snapshots themselves live
only in this tab’s memory. A **full reload** of the page empties those
snapshots; the inspector choices still return. A **new tab** has neither.

This is not a server archive and not a history of the market.

## How to use it
1. Open **Apps → Options Lab → Heatmap**.
2. Set the desk the way you work (symbol, listed expiration, template,
   side; on Width Fit, your weights and Heatmap or Ranking).
3. Leave — Analyzer, another app, or the Hub.
4. Return on **this tab**. The inspector matches what you set.

To start clean, open Heatmap in a **new tab**, or close this tab and open
Heatmap again.

## Expiration
The restored expiration is used only if that date is still **listed** on
the chain for this symbol. If it has dropped off (for example a 0DTE that
is no longer listed after the close), Heatmap picks a listed date that is
still there. It will not keep an expired date as if it were live.

## Width Fit
On the Width Fit template, this tab also remembers Heatmap vs Ranking,
Live vs Average, the window, cache size, Expand, and your seven weights.
See the **Width Fit** help topic for color tiles, ranking, and weights.

Average of colors is observation of listed fit on snapshots this tab held
— not a forecast.

## New tab
A new browser tab (or a new browsing session) starts from product
defaults: the usual symbol, a listed expiration, Advanced flies, Live,
Heatmap tiles. Nothing copies from another tab.

Two tabs can each have their own desk. They do not share Average memory.

## What this is not
Not a broker, fill, or advice. Not a saved layout on the server. Not a
layout that follows you to another computer. Not a promise that Average
still has snapshots after a reload. Tiles still use the held chain’s
listed mids and greeks. For a book P&L picture, use Analyzer and Surface.
