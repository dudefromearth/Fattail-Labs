# GEX (term mass)

**GEX (term mass)** is an Options Lab Runner template. It shows chain GEX (estimate) by strike and by listed expiration, with a companion profile and a NET footer. Open Options Lab → Runner and pick **GEX (term mass)**. Code id `gex-cal`.

Chain GEX (estimate) at this snapshot, not a direction. It is not true dealer positioning, not a forecast, and not a buy or sell cue. The gold mark is the largest absolute mass in the visible window.

If the expiration pack is not available, the grid stays empty and says so. It will not copy one expiration across fake columns.
